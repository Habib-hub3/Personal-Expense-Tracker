# Personal Expense Tracker

Keeping track of everyday spending should be simple. Personal Expense Tracker is a native iOS application designed to help users record, organize, and better understand where their money goes—all through a clean and familiar iPhone experience.

Built with Swift, UIKit, and Storyboards, the app allows users to manage their expenses in one convenient place. They can add, edit, search, filter, view, or delete transactions and organize them into categories such as Food, Transport, Shopping, Bills, Entertainment, Utilities, and Health. Users can also take a photo of a receipt or select one from their photo library and attach it to an expense for future reference.

Firebase Authentication provides secure account registration and login, while Cloud Firestore keeps expense data synchronized in real time. The app also gives users a clearer picture of their spending through overall and monthly summaries, category breakdowns, and visual progress indicators.

## Key Features

* Secure account registration and login
* Add, edit, view, and delete expenses
* Search for expenses by title
* Filter expenses by category or month
* Capture or upload receipt photos
* View overall and monthly spending summaries
* Track spending across different categories
* Support for BHD, USD, EUR, and GBP
* Choose a default expense category
* Switch between light and dark modes
* Set daily reminders to record expenses
* Manage profile and account settings
* Synchronize data in real time across sessions
* Navigate through a familiar, native iPhone interface

## Technologies Used

* Swift
* UIKit
* Storyboards and Auto Layout
* Firebase Authentication
* Cloud Firestore
* Cloudinary
* UserNotifications
* UserDefaults

Overall, this project demonstrates the development of a complete native iOS application—from responsive interface design and secure authentication to cloud-based data storage, receipt image handling, notifications, and personalized user settings. It combines practical financial tools with a simple experience that makes managing daily expenses easier.
